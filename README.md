# 💎 Onix Roleplay

Bem-vindo ao repositório oficial do **Onix Roleplay**, um servidor brasileiro de **SA-MP (San Andreas Multiplayer)** focado em oferecer uma experiência de Roleplay moderna, organizada e divertida.

---

## 📖 Sobre o projeto

O Onix Roleplay está sendo desenvolvido com foco em:

- 🎭 Roleplay realista
- ⚡ Sistemas exclusivos
- 🚓 Facções e organizações
- 💼 Empregos variados
- 🏠 Sistema de casas
- 🚗 Sistema de veículos
- ⛽ Sistema de combustível
- 📱 Interface moderna
- 💎 Sistema VIP
- 📈 XP e Level
- 🎁 Eventos e recompensas
- 🛠 Administração organizada

---

## 🚀 Tecnologias utilizadas

- Pawn
- SA-MP 0.3DL / 0.3.7
- ZCMD
- DOF2
- sscanf
- Streamer Plugin
